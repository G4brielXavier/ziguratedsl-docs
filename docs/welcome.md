# O que é Zigurate?

**Zigurate** é uma linguagem de dominio especifico (DSL) desenvolvida em *Rust* por um criador de mundo para criadores de mundos, focado em trazer organização, eficiência e uma nova forma trazer um mundo á vida.

Abaixo, está um simples "Hello World" na sintaxe do **Zigurate**:

```js
silim("Hello World!")
```

Para testar, execute isso no terminal:

```bash
enki run hello.zi
```
