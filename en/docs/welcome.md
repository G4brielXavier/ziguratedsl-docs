# What is Zigurate?

**Zigurate** is a domain-specific language (DSL) designed in *Rust* for *deep worldbuilding*, focused on bring organization, efficiency and a new way to become your world alive. 

Below, a simple "Hello World!" in **Zigurate**'s syntax:

```js
// hello.zi
silim("Hello World!")
```

To test, execute it in your terminal:

```bash
enki run hello.zi
```
