# Who create it and why?

Zigurate was designed by *Gabriel Xavier* or *dotxav* with intention of organize your own world. By him not have liked use others ways, he prefered ask for yourself:

> *"I'm programmer. I know code in Rust, why I don't build a language to organize my own world?"*

So, he decided to make it, step-by-step, calmly:
- *No anxious*
- *No returns*
- *Only for himself*

> *"I created it for myself, if you want to use, you can, feel free. The reason that I sharing it, because this project is a great experience, create a DSL by Zero in Rust, no external libs is not easy."*
